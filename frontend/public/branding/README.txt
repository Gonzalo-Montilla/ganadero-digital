Pega aqui tu logo oficial con estos nombres exactos:

- logo.png
- logo.ico (opcional, para favicon)

Rutas finales esperadas:
frontend/public/branding/logo.png
frontend/public/branding/logo.ico

Importante en Windows:
- No guardes como "logo.png.png" ni "logo.ico.ico"
- Si el archivo queda con doble extension, renombralo a logo.png / logo.ico

Recomendacion:
- Fondo transparente
- Minimo 512x512
- Formato PNG

Despues de cambiar logo.png, regenera favicons con fondo claro:
npm run generate:favicons
